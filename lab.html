Mijn IT Lab

Een volledig zelfgebouwde IT-omgeving met networking, servers, virtualisatie en cloud automatisatie. Dit lab simuleert een echte enterprise infrastructuur.

Lab infrastructuur

  • 1x TP-Link TL-ER6120 Router
  • 1x TP-Link T2600G-28TS (Layer 3 Core Switch)
  • L2 Switches: T1500G-10MPS, Cisco SG300-20, TL-SG1016DE, Cisco SG350-10MP
  • WiFi: 2x TP-Link EAP225 + Omada OC200
  • IP Camera’s: Reolink RLC-423 + RLC-420
  • NAS: QNAP TS-431XeU (CCTV), QNAP TS-832XU (lab), QNAP TS-469L (backup)
  • Servers: Supermicro 5018A-TN4 (Windows Server + Hyper-V), Custom i7-2600K ESXi host
  • Workstations: 4 desktops + 3 laptops

Netwerkdiagram

Netwerk & Infrastructuur

Mijn fysieke netwerk is opgebouwd als een enterprise-grade gesegmenteerde omgeving met VLANs, routing en switching binnen een professionele 18U patchkast.

  • VLAN-segmentatie en netwerkarchitectuur
  • Inter-VLAN routing via Layer 3 Core Switch
  • Netwerkisolatie en beveiliging (CCTV vs lab vs home)

Servers & Virtualisatie

Ik gebruik meerdere fysieke enterprise-servers en specifieke workstations om complexe virtualisatielabs en on-premises infrastructuren te draaien.

  • Virtualisatie met VMware ESXi en Microsoft Hyper-V
  • Nested labomgevingen voor Windows Server infrastructuren
  • Gecentraliseerde data- en opslagredundantie via RAID-NAS systemen

Cloud & Automatisatie

Sinds 2024 heb ik mijn focus succesvol uitgebreid naar cloudtechnologieën en Infrastructure as Code. Waar mijn homelab vroeger uitsluitend fysiek was, gebruik ik vandaag Microsoft Azure en GitOps-automatisering om geavanceerde cloud- en infrastructuurprojecten te ontwerpen, te beveiligen en te onderhouden.

  • Microsoft Azure: Cloud-native hosting en deployment via Azure Static Web Apps
  • Enterprise DNS- & domeinbeheer via Azure DNS-zones voor svenitguy.be
  • Terraform (Infrastructure as Code) voor het volledig geautomatiseerd uitrollen van cloud-infrastructuren
  • GitHub Actions CI/CD GitOps-pipelines met ingebouwde Trivy security scans en OIDC-authenticatie
  • FinOps kostenoptimalisatie via geautomatiseerde cron-jobs (70% besparing op Azure Bastion)
